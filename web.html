📋 Hướng dẫn
1
Build firmware: Arduino IDE → Sketch → Export Compiled Binary → lấy file .bin
2
Sửa WiFi: thay WIFI_SSID và WIFI_PASS trước khi build
3
Kết nối USB: cài driver CP2102/CH340. Dùng Chrome hoặc Edge (không dùng Firefox)
4
Nhấn ⚡ Flash, chọn cổng COM, chọn file .bin → đợi ~30–60s

Thay thế: esptool-js online · Flash Download Tool
